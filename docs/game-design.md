# ゲームデザイン方針（戦闘）

戦闘ルールの設計意図と調整の目安をまとめる。数値の実体は `backend/internal/game`（ルール）と `backend/internal/meta/catalog.go`（艦・敵・海域）にある。

## ゴール

1. **実力が勝敗を決める。** 艦のレア度やレベルは有利を生むが、読みと判断の差をひっくり返すほどではない。
2. **体感難易度がプレイヤーごとに変わる。** 経験（敵の動きの読み、速力順の把握）とセンス（特殊攻撃の狙い方）で同じステージが易しくも難しくもなる。
3. **作業化させない。** 同じ手順を繰り返せば勝てる「正解ルート」を作らない。慣れても毎回考えることが残る。

## 柱となる仕組み

### 同時決定 × 速力

両軍が同時に行動を決め、行動する艦の速力順に解決する（`game.Round` / `game.Initiative`）。

- 相手の行動を見てから動けないため、毎ターン「読み」が発生する。発見された艦を逃がすか撃ち合うか、相手は先に動けるか、を速力表から判断する。
- 速い駆逐艦で先に撃つ・移動する、遅い戦艦は相手の移動先を読んで撃つ、という艦種ごとの役割が生まれる。
- **魚雷は必ず後攻**。高威力の代わりに、先に沈められる・避けられるリスクを負う。

### 逃げ得の排除

以前は無制限の移動で撃たれたら逃げるだけで粘れた。現在は次の組み合わせで「撃ち合ったほうが得」にしている。

| 仕組み | 効果 |
| --- | --- |
| 艦種ごとの移動上限（戦艦・空母 1 / 巡洋艦・潜水艦 2 / 駆逐艦 3） | 大型艦は射程から出られない |
| 発見した水上艦は移動後も追跡 | 逃げても位置は割れたまま |
| 戦艦の十字着弾と水柱 | 外れても隣接艦を次ターンまで足止め |
| 高い致死性（会心 ×2・雷撃・精密爆撃） | 1〜2 発で沈むので、先に当てた側が有利 |
| 弾数の増加 | 攻撃の機会を増やし、撃ち合いを続けられる |

AI 同士のシミュレーションで、「発見されたら必ず逃げる」戦略は全ステージで通常戦略より勝率が低い（例: 3-4 で 54% → 9%）。

### 特殊攻撃（カットイン）

条件を満たすと必ず会心、または防御を無視する。条件はどれも**プレイヤーの判断で作るもの**で、運では発生しない。

| 名前 | 条件 | 効果 | 求められる読み |
| --- | --- | --- | --- |
| 着弾観測射撃 | 直前の行動で砲撃した地点へ、戦艦・巡洋艦の主砲を再び撃つ | 必ず会心 | 相手がその場に留まるか（水柱で足止めした直後は狙い目） |
| 精密爆撃 | 追跡中の敵艦を爆撃 | 対空・回避を無視 | 索敵 → 爆撃の連携と、相手が移動する前に撃てるか |
| 肉薄雷撃 | 2 マス以内の水上艦に魚雷が命中 | 必ず会心 | 雷跡で位置が割れるリスクを負って接近するか |

UI は条件が揃うと照準に「観測」マーカーと決定ボタンのヒントを出すが、自動では狙わない。

### 情報戦

- 潜水艦はソナーでしか見つからず、潜航移動で追跡を振り切れる。代わりに耐久は極小で、駆逐艦の砲撃は 2 倍。
- 雷撃・扇状雷撃は雷跡で発射位置が露見する。潜水艦は「撃つ → 潜って逃げる」の駆け引きになる。
- 空母の爆撃は位置を明かさないが、相手艦隊の対空合計で減衰する。対空の高い艦から沈めると爆撃が通りやすくなる。

### 作業化対策

- **海況**（出撃ごとに抽選）: 快晴 46% / 濃霧・時化・夜戦 各 18%。同じステージでも有効な艦と戦術が変わる。
- **CPU の同時決定**: CPU もプレイヤーの行動を見ずに決めるため、同じ手順が毎回通用しない。
- **弾切れは戦略的撤退**: 撃ち尽くした側は負け。最後に残った潜水艦を延々探す消化試合も起きない。

## Pay to win の抑制

- 同じ艦種の N と UR の差はおよそ 25%（耐久・火力など）。以前は耐久で最大 67% あった。
- レベル成長は連続的で緩やか（主要能力 +0.6%/Lv、Lv50 で約 +30%）。育成は遊んだ量に比例する。
- 限界突破（重複）は主にレベル上限を上げるだけ。単独の効果は会心 +1/★ と ★5 のスキル +1 のみ。
- 速力・装甲は成長しない。艦の個性として残す。

## ダメージ計算

```
ダメージ = 威力 × (0.85〜1.15) × (会心なら 2) × (駆逐艦の砲撃が潜水艦なら 2)
         × (1 − 装甲%)            … 魚雷は装甲を半分として扱う
         × 200 / (200 + 敵艦隊の対空合計)   … 爆撃のみ。精密爆撃は無視
```

回避判定は通常の回避率、爆撃は 1/4（濃霧では通常どおり）、全艦斉射と精密爆撃は回避不可。

## バランス調整の目安

`SIM=1 go test ./internal/meta -run Simulate -v` で全ステージを AI 同士で 400 戦ずつ回す。プレイヤー側は最も賢い AI（Lv3）と、そのステージ時点で平均的なプレイヤーが持っていそうな艦隊（1 海域: 初期 3 隻、4 海域: SR 4 隻 Lv25 など）を使う。人間は AI より上手くも下手にもなりうるので、あくまで相対的な目安。

| 指標 | 目安 |
| --- | --- |
| 通常ステージの勝率 | 70〜99%（海域の序盤ほど高く） |
| ボスステージの勝率 | 30〜55% |
| 平均決着ターン | ★ターン条件とほぼ同じ（上手い人だけが ★ を取れる） |
| 判定決着 | 数% 以下（撃沈で決着するのが基本） |
| 逃げ続ける戦略の勝率 | 通常戦略より低いこと |

## 今後の候補

- **陣形**: 出撃準備で選ぶ（単縦陣は火力、輪形陣は対空、警戒陣は対潜など）。編成に読み合いを足す。
- **CPU の性格**: 海域ごとに攻撃的・慎重・索敵重視などの思考傾向を持たせ、敵ごとの攻略法を生む。
- **旗艦ごとの決戦技**: 全艦斉射の形を旗艦の艦種で変える（戦艦は十字の長射程、空母は全域 2 マスなど）。編成の選択肢を増やす。
- **対人戦**: 同時決定の仕組みはそのまま対人に使える。
